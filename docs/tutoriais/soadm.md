# Modo somente administradores com `!soadm`

O modo somente administradores restringe as respostas do bot neste grupo ou
servidor. Enquanto estiver ativo, membros comuns não recebem respostas a
mensagens, comandos ou respostas automáticas acionadas por mensagens.

## Permissões e onde funciona

- **Quem pode ativar ou desativar:** administradores e pessoas com permissão
  para gerenciar mensagens.
- **Onde funciona:** grupos do WhatsApp e Telegram e servidores do Discord.
  No Discord, a configuração vale para o servidor inteiro.

## Comandos

```text
!soadm on
!soadm off
```

Use `on` para ativar e `off` para desativar. Se o prefixo do bot foi alterado,
substitua `!` pelo prefixo configurado.

## Painel web

Administradores também podem ativar ou desativar **Somente administradores** na
seção de administração do grupo ou servidor no painel web.
