# Autofigu — figurinhas automáticas

O comando `!autofigu` converte automaticamente fotos, GIFs e vídeos em
figurinhas no grupo. Quando ativado, qualquer mídia compatível enviada pelos
membros é transformada em sticker sem precisar de um comando manual.

> **Plataformas:** WhatsApp e Telegram apenas (não funciona no Discord).

## Permissões

- Administradores do chat
- Superusuários (owners)

## Subcomandos

| Comando | Descrição |
|---|---|
| `!autofigu on` | Ativa a conversão automática de mídias em figurinhas |
| `!autofigu off` | Desativa a conversão automática |
| `!autofigu status` | Exibe se o recurso está ativado ou desativado |
| `!autofigu help` | Mostra a ajuda do comando |

## Aliases

`!autofigurinha`

## Como usar

### Ativar

```
!autofigu on
```

Após ativado, toda foto, GIF ou vídeo enviado no grupo será convertido em
figurinha automaticamente.

### Desativar

```
!autofigu off
```

### Consultar status

```
!autofigu status
```

O bot responde informando se o autofigu está ativado ou desativado no chat.

## Observações

- Funciona **apenas em grupos** — não pode ser configurado no privado.
- Exclusivo para **WhatsApp** e **Telegram**.
